# Clay Dev Studio

Portfólio profissional de desenvolvimento web e mobile com design claymorphic moderno.

## 🚀 Sobre o Projeto

Este é um portfólio pessoal desenvolvido para showcasing de projetos de desenvolvimento web e mobile. O site apresenta uma estética claymorphic única com animações suaves e design responsivo.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com:

- **Vite** - Build tool e dev server
- **TypeScript** - Tipagem estática
- **React** - Biblioteca UI
- **Framer Motion** - Animações
- **Tailwind CSS** - Estilização
- **shadcn/ui** - Componentes UI
- **Lucide React** - Ícones

## 📦 Instalação e Execução

### Pré-requisitos

- Node.js (versão 16 ou superior)
- npm ou yarn

### Passos para rodar localmente

```sh
# Clone o repositório
git clone <URL_DO_REPOSITORIO>

# Navegue até o diretório do projeto
cd clay-dev-studio-main

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

O projeto estará disponível em `http://localhost:5173`

## 🏗️ Build para Produção

```sh
# Gerar build de produção
npm run build

# Preview do build de produção
npm run preview
```
