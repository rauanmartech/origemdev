# 16\. Observação para Geração Automatizada

A automação de currículos deve tratar cada projeto como um conjunto de:

* `project\_name`
* `category`
* `domain`
* `description`
* `responsibilities`
* `technologies`
* `technical\_skills`
* `business\_skills`
* `keywords`
* `relevance\_by\_role`

O gerador deve **selecionar somente as experiências relevantes para cada vaga**, priorizando correspondência entre:

1. Tecnologias exigidas na vaga.
2. Área de atuação.
3. Senioridade.
4. Responsabilidades descritas.
5. Palavras-chave presentes na descrição da vaga.
6. Complexidade técnica demonstrada pelo projeto.

Não devem ser inventadas métricas, cargos, resultados financeiros, número de usuários ou tecnologias que não estejam documentados.

A personalização deve alterar principalmente a **ordem, seleção e ênfase das experiências**, mantendo os fatos técnicos dos projetos consistentes com a experiência real.
